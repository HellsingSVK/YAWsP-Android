# YAWsP pre Android v0.5.1

Kompletný zdrojový projekt natívnej Android aplikácie (Kotlin + Jetpack Compose + Media3 ExoPlayer).

## Rýchle zostavenie `.apk` cez GitHub
1. Nahraj obsah tohto priečinka (vrátane `.github`) do repozitára na GitHube.
2. Otvor záložku **Actions** -> **Build Android APK** -> po dokončení stiahni **YAWsP-Android-APK** zo sekcie **Artifacts**.
